# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest based on user-provided inputs.

## Features

- Accepts principal amount from the user.
- Accepts rate of interest.
- Accepts the time period.
- Calculates simple interest using the mathematical formula.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used

- Bash
- Shell Scripting
- Git and GitHub

## Usage

Run the `simple-interest.sh` script in a Bash terminal and enter the principal amount, rate of interest, and time period when prompted.
